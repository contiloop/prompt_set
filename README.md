# Prompt Set

A personal collection of AI instructions and prompts, maintained here as the source for use across tools.

## Instructions

### [Global Instructions](global%20instruction.md)

**Purpose:** Guide AI to communicate clearly, follow the intent and scope of a task, and seek real conditions when meaningful testing depends on them. These criteria help reduce unnecessary verbosity, work beyond the assigned task, and mock testing that cannot establish the result that matters.

**When to use:** Apply as persistent defaults across writing, coding, prompt creation and revision, and handoffs between agents.

**How to use:** Include the document's contents in your AI tool's user-level global instruction file. Preserve any existing instructions you still need. Use the filename and location recognized by that tool, then verify that a new session loads the instructions.
